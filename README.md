# 香港街角

香港獨立食遊 PWA。茶餐廳奶油色、招牌紅與電車綠；不沿用峴港資料、收藏 namespace、酒店、日期或手信功能。

## 開發與驗證

`npm ci` → `node scripts/build-data.mjs` → `npm run dev`。
發佈前：`npm test`、`npm run validate:data`、`npm run build`。GitHub Pages 使用 main 的 deploy.yml。手機尺寸瀏覽器 QA 不等於 iPhone standalone 實機驗收。

## 收錄規則

- 一般餐廳：Google 至少 4.2／300 則；Cafe／甜品：至少 4.3／150 則。
- 米芝蓮或具可靠獨立推薦依據的代表性老店：至少 4.0，逐店列明例外依據。
- OpenRice 作正反食評、同分店及資料交叉參考，不換算星數。
- 明確利益換好評、要求五星、其他刷分證據：排除。PR-only 或未完成公開樣本審核：不得發佈。
- 一般折扣、服務補救或不帶利益條件的邀評，不自行推斷成刷分；邀評不作獨立推薦證據。
- 只收正確分店，排除純素食餐廳。查閱日期不等同評論日期或 Google 即時查核。
- 公開樣本及索引搜尋不能保證不存在未公開 PR；不可標榜「認證零 PR」。

來源：data/places.mjs。build-data.mjs 組合照片授權產生 public/places.json。新增店需通過 admission 與 audit，不能只改評分繞過審核。

## 時間與圖片

14／16 有結構化時間；波記來源衝突、星光大道無官方完整時間表，維持未知，不判打烊。時間優先店方官網，其次指南與同址平台；未解衝突明示。公眾假期使用政府 2026 通告，受假期影響的店在其他年份回到未知。

7 張 CC 實景：6 景點及添好運门面。其餘 9 餐廳缺少合適已核實可用門面照，顯示待核實。歷史照片年份列在到場提示，不用生成照、食物照或錯分店頂替。縮圖 WebP 的作者、原檔和授權在 data/photo-licenses.json 與詳情卡。CC BY-SA 縮圖沿用原授權，照片與程式碼授權分開。

## 已知界線

首版 10 餐廳、6 景點，不是全港普查。Google 分數是 Wanderlog 明示為 Google 的轉載，可能落後；人均是規劃估算非報價；營業狀態不是即時店況。

收藏、去過和口袋行程存在本機 hk-street:v1:。可分享地點連結，但不宣稱跨裝置同步或共同編輯。檢查更新只下載已發佈資料，不自動搜尋店家。首次使用及未快取地圖需要網絡。
